### useState, useEffect, etc.
- useState is used to manage a state in a component.
- useEffect is used to run side-effect code within a component.
- useParams is used to pass dynamic URL parameters provided the route is matched. Also inherits from parent routes. Example: Assuming a route pattern like /posts/:postId is matched by /posts/123 then params.postId will be "123".


### Navigation
NavLink is a specialized wrapper around React Router's Link component that automatically tracks whether its route is currently active, pending, or transitioning
